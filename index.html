1. Заголовки и списки

Теги (h1) – (h6) — разметка специальных заголовков разных уровней.

  • Тег (ul) — элемент маркированного списка (блочный).
  • Тег (li) — элемент списка (маркированного или нумерованного).
  1. Тег (ol) — элемент нумерованного списка (блочный).
  2. Тег (li) — элемент списка.

2. Форматирование текста

Этот текст выделен жирным (b / strong), курсивом (i / em),
подчеркнутым (u), зачеркнутым (s) или моноширинным (code).

Чтобы сделать текст маленьким или выделенным фоном:
Дата моего рождения (small),
очень важный текст (mark).

Нижний и верхний индексы:
H2O (sub), 24 (sup). А также разделительная линия (hr).

3. Ссылки и кнопки

Чтобы сделать элемент ссылкой, используют тег (a):
нужно использовать тег a с атрибутами (href="...") и (target="_blank").

Также можно сделать якорную ссылку внутри страницы через атрибуты:
(href="#id_элемента") и (id="id_элемента").

Для скачивания файлов, отправки писем или звонков применяют атрибуты/схемы:
(download), (mailto:), (tel:).

Для создания интерактивных кнопок используют тег (button).

Основные типы (type):

  • (button) — кнопка по умолчанию для обычных скриптов.
  • (submit) — отправка данных формы на сервер.
  • (reset) — сброс введенных данных в форме.

4. Изображение и видео

Для добавления фото и видео используются теги (img) и (video) с атрибутами:
(src="...") (путь к файлу) и (loading="lazy") (ленивая загрузка).

Текстовое описание задается через (alt="..."), а размеры — через (width="...") и (height="...").

5. Теги и цитаты

Для выдержки блочных цитат используется тег
(blockquote), а для указывания источника/автора — тег (cite).

Тег (q) используется для создания короткой строчной цитаты внутри текста.

6. Медиа контент

Для воспроизведения звука и видео нужны теги (audio) / (video) с атрибутом (controls).

Вложенный тег (source) с атрибутом (type="...") позволяет подключить разные форматы медиафайлов.

Атрибуты (autoplay) (автостарт), (muted) (без звука) и (loop) (повтор) управляют воспроизведением.

Атрибут (playsinline) внутри тега (video) разворачивает на весь экран у мобильных устройств.

7. Таблицы

Тег (table) создает таблицу, (tr) — строку,
(th) — заголовочную ячейку, а (td) — обычную ячейку с данными.

Тег (caption) задает название таблицы, (thead) группирует шапку,
(tbody) — тело, а (tfoot) — подвал таблицы.

Атрибуты (colspan="...") и (rowspan="...") объединяют ячейки
по горизонтали и вертикали соответственно.

Пример таблицы:
Номер За день: % За неделю: % За месяц: %
1 1% 7% 30%
2 2% 14% 60%
3 3% 21% 90%
4 4% 28% 100%
Всего %: 10% 70% 280%
Итог: Ты станешь лучше всего за пару месяцев

8. Формы и ввод данных

Тег (form) используется для объединения всех
элементов ввода информации и отправки их на сервер.

Тег (fieldset) используется для визуальной группировки элементов
формы, а тег (legend) задает заголовок для этой группы.

Тег (label) используется для создания текстовых меток
к элементам формы (связывается с полем через атрибуты for и id).

Тег (input) используется для создания различных полей ввода данных.

Очень важный атрибут для input — (type), который определяет тип поля ввода.

Атрибут required указывает, что поле обязательно для заполнения перед отправкой формы.

8.1 Input и его вариации

У полей ввода есть вспомогательные атрибуты: id (для связи с label)
и name (определяет имя поля для распознавания данных на сервере).

В атрибуте type доступно множество вариантов:
(email, text, password, url, tel, search, date, color, file, checkbox, radio, range, number) и т.д.

8.2 Select и другие элементы ввода

Тег (select) используется для создания выпадающего списка.
Вложенный тег (option) определяет варианты выбора.

Тег (optgroup) с атрибутом label используется
для группировки похожих опций внутри списка.

Тег (textarea) создает многострочное поле
для ввода произвольного текста.

Атрибут disabled делает элемент неактивным для выбора,
а selected выбирает пункт по умолчанию.

Полезные атрибуты для полей ввода:

  • placeholder — текстовая подсказка внутри пустого поля.
  • readonly — делает поле доступным только для чтения (нельзя редактировать).
  • autofocus — автоматически устанавливает курсор в поле при загрузке страницы.
  • autocomplete="on/off" — включает или отключает автозаполнение браузером.
  • minlength / maxlength — задает минимальную и максимальную длину вводимого текста.
  • rows / cols — задают количество строк и столбцов в теге textarea.
  • inputmode — выбирает вид мобильной клавиатуры (numeric, tel, decimal, url).
  • pattern — задает регулярное выражение для проверки правильности ввода.
  • spellcheck="true/false" — включает или отключает проверку орфографии.

9. Семантические теги

Тег (header) представляет собой группу, объединяющую шапку документа (верхушку сайта).

Тег (footer) представляет собой группу, объединяющую подвал документа (низ сайта).

Тег (main) представляет собой уникальное основное содержание документа.

Тег (section) представляет собой смысловой раздел документа с обязательным использованием заголовков.

Тег (article) представляет собой независимую часть содержания, которая имеет смысл сама по себе (например, новость или статья).

Тег (aside) представляет собой боковую панель или дополнительный блок с косвенным содержанием.

Тег (nav) представляет собой блок навигационных ссылок по сайту.

10. Векторная графика

Тег (svg) используется для создания и контейнеризации векторной графики.

Вспомогательные теги внутри SVG:
(circle) — для кругов,
(polyline) — для ломаных линий,
(path) — для сложных линий и кривых.

11. Глобальные и актуальные атрибуты

Глобальные атрибуты — это параметры, которые можно применить практически к любому HTML-тегу:

  • class — определяет имя класса для групповой стилизации элементов через CSS.
  • id — определяет уникальный идентификатор конкретного элемента на странице.
  • title — создает всплывающую текстовую подсказку при наведении мышкой.
  • hidden — полностью скрывает элемент со страницы.
  • tabindex — определяет порядок перехода по элементам с помощью клавиши Tab.
  • lang — определяет язык содержимого внутри элемента.
  • contenteditable — делает содержимое элемента редактируемым прямо на странице.
  • style — задает прямые (встроенные) CSS-стили для элемента.
  • data-* — используется для создания собственных пользовательских атрибутов.
