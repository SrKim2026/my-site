ШПАРГАЛКИ ПО CSS

Это вторая страница моей шпаргалки, и она будет содержать информацию о CSS, а так же использоваться для примера селекторов и разного выученного материала.

1. CSS - Селекторы

Самый простой селектор — это селектор тега, который выбирает абсолютно все элементы указанного типа (p { свойства }).

Самый часто используемый — селектор класса, который выбирает все элементы с указанным классом. Пишется через точку (.class-name { свойства }).

Селектор идентификатора выбирает один уникальный элемент с конкретным ID. Пишется через решетку (#id-name { свойства }).

Селектор атрибута выбирает элементы, у которых есть определенный атрибут или его значение ([type="text"] { свойства }).

Специальные символы и комбинации атрибутов:

  • * — универсальный селектор (выбирает вообще все элементы на странице).
  • [attr^="val"] — выбирает элементы, где значение атрибута начинается с указанного текста.
  • [attr$="val"] — выбирает элементы, где значение атрибута заканчивается на указанный текст.
  • [attr*="val"] — выбирает элементы, значение атрибута которых содержит указанный текст в любом месте.
  • [attr|="val"] — выбирает элементы с точным значением или начинающиеся с этого слова и дефиса (например, zh-CN).
  • [attr="val" i] — делает поиск атрибута нечувствительным к регистру (игнорирует заглавные и строчные буквы).

Селекторы связей (Комбинаторы):

  • A B (пробел) — селектор потомков (выбирает все элементы B, лежащие глубоко внутри A).
  • A > B — селектор дочерних элементов (выбирает только прямых «детей» элемента A, на один уровень вложенности).
  • A + B — селектор соседнего элемента (выбирает элемент B, который идет сразу же после A).
  • A ~ B — селектор всех последующих сестер/братьев (выбирает все элементы B, идущие после A на том же уровне).

Блочная модель (Box Model)

Каждый элемент в CSS представляет собой прямоугольный блок, который состоит из 4 слоев (изнутри наружу):

  • Content — сам контент (текст, картинка).
  • padding — внутренний отступ (пространство между контентом и рамкой).
  • border — рамка (граница вокруг контента и padding).
  • margin — внешний отступ (пространство снаружи, отталкивает соседние блоки).

Синтаксис отступов (часы: верх -> право -> низ -> лево):

  • padding: 10px; — отступ 10px со всех 4 сторон.
  • padding: 10px 20px; — 10px сверху/снизу, 20px слева/справа.
  • padding: 10px 20px 15px 5px; — верх (10px), право (20px), низ (15px), лево (5px).

Главное правило верстки:

box-sizing: border-box; — заставляет padding и border входить в общую ширину (width) блока, а не раздувать его наружу.
